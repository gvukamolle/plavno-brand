# Плавно — публичный лендинг

[Открыть сайт](https://gvukamolle.github.io/plavno-brand/) · [Фирменный стиль](https://gvukamolle.github.io/plavno-brand/brand.html)

Описание продукта, интерактивный обзор интерфейса, рабочие сценарии и материалы бренда.
Основной фирменный цвет — снежно-белый `#ffffff`.

Интерфейс на лендинге использует демонстрационные данные и заранее подготовленные
примеры ответов. Он не подключён к корпоративному приложению или рабочим данным.

Статическая страница без сборки и внешних зависимостей. Публикация через GitHub Pages.
Для локального просмотра: `python3 -m http.server 8785 --bind 127.0.0.1`.

Шрифты Golos Text и IBM Plex Mono распространяются по SIL Open Font License;
лицензии включены в `assets/fonts/`. Название и знаки Плавно сохраняют права
своих правообладателей; публичный доступ к файлам не означает передачу прав на бренд.

## Визуальный язык 1.1.0

Лендинг использует исходный жест руки с коричневой манжетой и 11 настоящих
снимков приложения. Все данные на снимках синтетические. Внешние интеграции и
ответ Сола подготовлены локально; это не доказательство их живого прохождения.
Стартовый тестовый дашборд с приветствием исключён владельцем продукта.
Новые позы отложены до фотографий руки владельца; отклонённые генерации не включены в брендкит.

Новости: штатный Krea 4:5, экспорт 1080 × 1350. Правила — brand.html и
assets/media-presets.json. Primary остаётся снежно-белым #FFFFFF.
